A language can be described using a fixed set of parameters, each with a different set of parameters. This is expressed as dictionary structure like this:

{
'basic word order': ['SVO', 'SOV', 'VSO', 'VOS', 'OSV', 'OVS'],
'number of grammatical genders': ['none', '1', '2', '3', '4', '5+'],
'past tense marking': ['none', 'suffix', 'prefix', 'auxiliary' 'other'],
'consonant inventory': ['small, less than 15 consonants', 'medium, from 16-30 consonants', 'large, 30 or more consonants'],
'stress pattern': ['initial', 'final', 'penultimate', 'antepenultimate', 'lexically determined'
}

For example, French would be defined like this:

{
'basic word order': ['SVO'],
'number of grammatical genders': ['2'],

'consonant inventory: ['medium, from 16-30 consonants'],
'stress pattern': ['final']
}
